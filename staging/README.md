# محیط آزمایشی معرفت

## وضعیت ثبت‌شده
- پروژه Supabase: `marefat-school-test`، شناسه `yyqeymyopawhaniyemqo`.
- پایگاه داده اصلی در این مرحله فقط خوانده شد؛ هیچ رکورد واقعی کپی نشد.
- ساختار منتقل‌شده: ۳۵ جدول، ۲۳ نما، ۷۷ تابع، ۵ enum، ۳۲ sequence، ۱۳۰ constraint، ۹۷ index مستقل از constraint، ۵۲ سیاست و ۷ trigger.
- تطابق تعریف توابع، ستون‌ها، RLS، مجوزهای جدول و تابع، نماها، ایندکس‌ها، قیود، triggerها و تنظیمات sequence با اثر انگشت تأیید شد: schema-verification.json.
- schema-baseline.sql فقط ساختار public و v5_private است؛ نسخه کامل پشتیبان سرویس، تنظیمات Auth، فایل‌های Storage و داده‌های کاربران نیست. فقط روی پروژه آزمایشی خالی اجرا شود، نه تولید.
- کار زمان‌بندی ثبت خودکار هر ۳۰ ثانیه فعال شد؛ اجرای موفق آن مشاهده شد.
- دو دانش‌آموز ساختگی STAGING-STUDENT-001 و STAGING-STUDENT-002، یک درس و آزمون سه‌سؤالی ساخته شدند.

## آزمون‌های انجام‌شده
- ۱۰ تست JavaScript صفحه آزمون پاس شد.
- ۳ تست ساخت نسخه جدا پاس شد: جداسازی نشانی/کلید، عدم تغییر منبع، جلوگیری از backend ناشناخته و بازنویسی منبع.
- tests/expiry-finalization.sql در محیط تست پاس شد؛ داده و trigger موقت آن rollback می‌شود.
- check-anonymous-role.sql با نقش anon واقعی پایگاه داده پاس شد: شروع، کد استاندارد، مهلت، رد دانش‌آموز نامعتبر، ذخیره، ادامه، نمره ۱۰۰٪، ثبت مجدد بدون تغییر و منع دسترسی به پنل مدیر/جدول دانش‌آموز/کلید پاسخ.
- این تست SQL جای تست HTTP و مرورگر را نمی‌گیرد.
- اجرای check-api.py از این محیط به تأیید شبکه متوقف ماند و تکمیل نشد؛ نتیجه موفق HTTP گزارش نمی‌شود.
- بررسی امنیت ۳ اطلاعیه RLS بدون policy برای جداول قدیمی و ۶۷ هشدار توابع SECURITY DEFINER داد. این هشدارها با کپی ساختار حذف نشده‌اند؛ مجوزهای عمومی توابع دانش‌آموز عمدی‌اند، اما بررسی کامل مجوزهای همه عملیات مدیر هنوز لازم است. [راهنمای هشدار توابع عمومی](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable).

## ساخت سایت آزمایشی
در ریشه مخزن اجرا کنید:
```sh
python tests/staging-build.test.py
python staging/build.py
```
خروجی در .staging-dist ساخته می‌شود؛ اگر از قبل پر باشد، ابزار برای جلوگیری از بازنویسی ناخواسته متوقف می‌شود. برای ساخت دوباره مسیر خروجی خالی بدهید.
خروجی فقط ۲۱ صفحه HTML و robots.txt و _headers دارد؛ SQL، تست‌ها و مخزن را منتشر نمی‌کند.
تمام صفحات برچسب محیط آزمایشی، noindex و محدودیت connect-src برای پروژه تست دارند. فایل‌های HTML تولید تغییر نمی‌کنند.
کلید داخل نسخه تست publishable است؛ کلید مدیریتی در آن وجود ندارد. noindex به معنی حفاظت با رمز نیست، پس فقط داده ساختگی استفاده شود.

## انتشار هنوز انجام نشده
تنظیمات مستقل wrangler-staging.jsonc با نام marefat-shimi-test و assets.directory برابر .staging-dist آماده است.
حساب Cloudflare در این محیط دسترسی انتشار ندارد؛ تا احراز هویت/اتصال مجاز انجام نشود لینک عمومی آزمایشی وجود ندارد.
پس از فراهم شدن دسترسی، فقط همین تنظیمات آزمایشی منتشر شود؛ فایل wrangler-cloudflare.jsonc فعلی ریشه مخزن را سرو می‌کند و نباید برای نسخه تست استفاده شود.
[مستندات رسمی Static Assets](https://developers.cloudflare.com/workers/static-assets/) مبنای تنظیم خروجی است.

## موارد باقی‌مانده
۱. دسترسی انتشار Cloudflare و انتشار نسخه آزمایشی.
۲. ساخت حساب مدیر آزمایشی از مسیر رسمی Auth؛ حساب واقعی کپی نشده است.
۳. تست مرورگر دانش‌آموز و مدیر، موبایل، قطع اینترنت، پایان مهلت و گزارش‌ها.
۴. رفع ایرادهای تست عملی و تکرار آزمون‌ها.
۵. انتشار تولید تنها پس از تأیید نتایج.
