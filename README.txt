نسخه چهارم سامانه آزمون شیمی دهم

این نسخه برای استقرار واقعی طراحی شده است:
- رابط دانش‌آموز
- ثبت نتیجه در Supabase در صورت تنظیم CONFIG
- احراز هویت مدیر با Supabase Auth
- داشبورد مدیر
- گزارش دانش‌آموزان، کلاس‌ها، سؤال‌ها و فصل‌ها
- خروجی CSV
- حالت محلی برای تست، اگر CONFIG خالی باشد

مراحل استقرار:
1. یک پروژه Supabase بسازید.
2. فایل supabase.sql را در SQL Editor اجرا کنید.
3. در Authentication یک کاربر مدیر بسازید.
4. مقدار URL و anon key را در CONFIG فایل index.html قرار دهید.
5. index.html را روی یک هاست استاتیک قرار دهید (مثلاً GitHub Pages یا Netlify).
6. لینک عمومی را برای دانش‌آموزان ارسال کنید.

نکته امنیتی:
anon key برای کلاینت طراحی شده است؛ service_role key نباید در مرورگر قرار گیرد.
برای امنیت بالاتر، ثبت نهایی آزمون در محیط تولید بهتر است از Edge Function انجام شود تا دانش‌آموز نتواند پاسخ/نمره را دستکاری کند.
